# 53. Maximum Subarray

- **Уровень:** Medium
- **Паттерн:** Алгоритм Кадане
- **Ссылка:** https://leetcode.com/problems/maximum-subarray/

## Краткое условие:
Дан массив чисел `nums`. Найти подмассив с максимальной суммой

## Идея решения:

Использовать алгоритм Кадане:
1. Создать переменные `max` и `sum`, равные первому элементу массива
2. Пройтись по массиву от второго элемента (`i = 1`):
    - Переменная `sum`: выбрать максимум между текущем элементом и суммой с текущим элементом
    - Переменная `max`: записать максимальное значение между `sum` и `max`
3. Вернуть максимальную сумму подмассива `max`

## Код:
```java
class Solution {
    public int maxSubArray(int[] nums) {
        int max = nums[0];
        int sum = nums[0];

        for (int i = 1; i < nums.length; i++) {
            sum = Math.max(nums[i], sum + nums[i]);
            max = Math.max(sum, max);
        }
        return max;
    }
}
```

## Сложность:
- **Время:** O(n)
- **Память:** O(1)
